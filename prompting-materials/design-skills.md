Format as markdown for me# Claude Skills for Product Design — Link Directory

Companion to your ranked report. Same order, same tiers, same numbering — now with a link for every skill.

**How the links work:**
- Many skills live as **folders inside a bigger repo** (that's how the skills format works — each skill is a folder with a `SKILL.md` file). For those, the link takes you to the folder or the parent collection.
- Links marked **†** were surfaced during the original research but I couldn't re-verify the exact URL today. If one 404s, search the skill name on GitHub — the name is correct even if the repo has moved.
- Connector links (Tier 5) follow the `claude.com/connectors/<name>` pattern. If a specific page has moved, browse from the [Figma connector page](https://claude.com/connectors/figma), which is confirmed live.
